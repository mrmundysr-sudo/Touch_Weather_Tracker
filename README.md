# Touch Weather Tracker

A U.S.-wide everyday weather and severe-weather app for Android and iOS.

## Claude handoff
- Android implementation: `claude/android`
- iOS implementation: `claude/ios`, based on the completed Android app
- Approved product brief: [docs/PRODUCT_VISION.md](docs/PRODUCT_VISION.md)
- Decisions: [docs/DECISIONS.md](docs/DECISIONS.md)
- Implementation sequence: [docs/DEVELOPMENT_PLAN.md](docs/DEVELOPMENT_PLAN.md)

Claude is authorized to build the complete Android app first and then the equivalent iOS app. The owner will test both; the owner and Codex will conduct a full review before any store submission. Do not submit or publish.

This project uses the Mundy App Template's handoff, knowledge, component discovery, and APK delivery conventions. Android source and build files will be created on `claude/android`.
